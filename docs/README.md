# 방탈출 예약 시스템 - 인증 단계

방탈출 예약, 테마, 예약 시간을 관리하는 백엔드 서비스입니다.

이번 단계부터 웹 사용자는 로그인한 뒤 예약 서비스를 사용합니다. 기존에는 예약자 이름(`name`)을 본인 확인 값으로 사용했지만, 이제 사용자 예약 생성, 조회, 변경, 취소를 로그인한 회원 기준으로 처리합니다.

> 로그인 상태 유지는 서버 인메모리 세션으로 구현하고, 인증 공통 처리는 Interceptor로 분리합니다.

## API 명세

## 1. 로그인 (Auth)

| 기능 | Method | URL | 설명 |
| --- | --- | --- | --- |
| 웹 로그인 | `POST` | `/login/web` | 로그인 ID와 비밀번호로 로그인하고 세션 ID를 쿠키로 응답한다. |
| 모바일 로그인 | `POST` | `/login/mobile` | 로그인 ID와 비밀번호로 로그인하고 세션 ID를 응답 본문으로 반환한다. |

### 로그인 요청

```json
{
  "loginId": "whale",
  "password": "password"
}
```

### 로그인 응답

웹 로그인에 성공하면 세션 ID를 쿠키로 응답한다.

```json
{
  "id": 1,
  "loginId": "whale",
  "name": "고래"
}
```

모바일 로그인에 성공하면 세션 ID를 응답 본문으로 반환한다.

```json
{
  "sessionId": "d80c6f2d-1f99-4a8a-87b5-e7f817a9e4ad"
}
```

## 예외 및 에러 응답 명세

### 예외 구조

커스텀 예외는 HTTP 상태 코드의 맥락을 가지는 부모 예외를 상속받아 구현한다.
- `RoomescapeException`: 최상위 도메인 예외
- `BadRequestException`: 잘못된 요청 예외, 400 응답
- `UnauthorizedException`: 인증 실패 예외, 401 응답
- `NotFoundException`: 리소스를 찾을 수 없는 예외, 404 응답
- `ConflictException`: 현재 리소스 상태와 요청이 충돌하는 예외, 409 응답

### 에러 응답 형식

모든 에러 응답은 JSON 형식으로 반환한다.

```json
{
  "message": "잘못된 정보입니다. 다시 시도해주세요."
}
```

### HTTP 상태 코드 매핑 기준

인가 원칙: 인증된 사용자가 다른 회원의 예약에 접근하는 소유권 불일치 상황은 `403 Forbidden`으로 반환한다.
존재하지 않는 리소스는 `404 Not Found`, 인증되지 않은 요청은 `401 Unauthorized`로 구분한다.

| 상태 코드 | 부모 예외/처리기 | 발생 케이스 | 응답 메시지 예시 |
| --- | --- | --- | --- |
| `400 Bad Request` | `HttpMessageNotReadableException` | JSON 본문이 잘못되었거나 날짜/시간 역직렬화에 실패한 경우 | `"요청 본문 형식이 올바르지 않습니다."` |
| `400 Bad Request` | `MethodArgumentNotValidException` | `@Valid` 검증에 실패한 경우 | `"예약 날짜는 필수입니다."` |
| `400 Bad Request` | `BadRequestException` | 과거 날짜 또는 시간으로 예약하는 경우 | `"과거 날짜/시간으로는 예약할 수 없습니다."` |
| `401 Unauthorized` | `UnauthorizedException` | 로그인 정보가 잘못된 경우 | `"잘못된 정보입니다. 다시 시도해주세요."` |
| `401 Unauthorized` | 인증 Interceptor | 인증이 필요한 API에 세션 없이 접근한 경우 | `"인증이 필요합니다."` |
| `403 Forbidden` | `ForbiddenException` | 예약 소유 회원이 일치하지 않는 경우 | `"접근 권한이 없습니다."` |
| `404 Not Found` | `NotFoundException` | 존재하지 않는 예약을 조회, 변경, 취소하는 경우 | `"해당 예약을 찾을 수 없습니다."` |
| `409 Conflict` | `ConflictException` | 같은 날짜, 시간, 테마에 이미 예약이 존재하는 경우 | `"해당 시간과 테마에는 이미 예약이 존재합니다."` |
| `409 Conflict` | `ConflictException` | 이미 취소된 예약을 변경하거나 다시 취소하는 경우 | `"이미 취소된 예약입니다."` |
| `500 Internal Server Error` | `Exception` | 서버 내부 오류 | `"서버에 일시적인 문제가 발생했습니다."` |
